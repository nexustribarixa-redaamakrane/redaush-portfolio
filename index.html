💻 Featured Software Project

fModLoader (FML)

Open-Source Font Glyph Modification Utility
v1.0.4 BETA Python 3.9+ PyQt6 fontTools

fModLoader is a sleek, open-source desktop application designed for dynamic font glyph modification on Windows. It empowers font artists, modders, and developers to create, edit, and patch custom glyph modifications directly onto compatible font files without the need for expensive commercial font editors.

🎨 Advanced Vector Editor

  • Built-in Glyph Editor: Full FontForge-inspired grid layout with real-time vector previews.
  • 13 Vector Drawing Tools: Features a Bezier Pen, Knife tool with intersection detection, Node Editor, Ruler, and Shape tools.

⚡ Powerful Backend & Scripting

  • SVG Integration: Seamlessly import SVG files and apply them to specific glyph ranges.
  • Scripting Environment: Built-in code editor supporting Python, FontForge .pe, and Cython scripts.
